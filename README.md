# Shipment Status Classifier API

Machine Learning API that predicts internal shipment statuses from external logistics status descriptions.

---

## Tech Stack

- Python
- Scikit-learn
- FastAPI
- TF-IDF
- Logistic Regression

---

## Features

- NLP preprocessing
- TF-IDF vectorization
- ML classification
- FastAPI REST API
- Confidence score prediction
